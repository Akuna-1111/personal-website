# 设计师个人网站

这是一个暗黑风格的个人作品集网站，专为拥有10多年经验的设计师打造。

## 功能特性

- 固定右上角菜单按钮（红色图标）
- 点击按钮滑出四个次级页面菜单：个人简介、项目经历、工作经历、资质证书
- 页面滚动时菜单按钮保持固定
- 暗黑风格设计：纯黑背景、红色图标、白色/灰色文字
- 使用思源宋体（标题）和思源黑体（正文）字体，支持中英文混合排版
- 标题文字具有滚动动画效果
- 响应式设计，适配移动设备

## 文件结构

- `index.html` - 主页面结构
- `style.css` - 样式表
- `script.js` - 交互脚本
- `open.bat` - 在浏览器中打开的批处理文件（双击运行）

## 内容定制

### 1. 修改菜单项
在 `index.html` 第21-24行修改菜单项文本和链接：
```html
<li><a href="#about">个人简介</a></li>
<li><a href="#projects">项目经历</a></li>
<li><a href="#work">工作经历</a></li>
<li><a href="#certificates">资质证书</a></li>
```

### 2. 修改主页内容
每个部分都有对应的ID：
- `#about` - 个人简介
- `#work` - 工作经历
- `#projects` - 项目经历
- `#certificates` - 资质证书
- `#contact` - 合作联系

### 3. 修改样式
在 `style.css` 中可调整：
- 颜色变量：红色 `#ff0000`，黑色 `#000`，灰色 `#ccc`
- 字体大小和间距
- 动画效果

### 4. 添加更多动画
在 `script.js` 中可扩展交互效果，现有功能：
- 菜单切换
- 平滑滚动
- 标题进入视口动画

## 字体使用
通过Google Fonts加载思源宋体（Noto Serif SC）和思源黑体（Noto Sans SC），确保中英文排版美观。

## 浏览器兼容性
支持现代浏览器（Chrome、Firefox、Safari、Edge）。
